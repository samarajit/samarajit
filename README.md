### / About Me

I am a second-year Bachelor of Computer Applications (BCA) student based in Maharashtra. My technical journey is driven by a focus on data and automation, with a clear career roadmap: mastering Machine Learning Engineering, and ultimately architecting systems as an MLOps Engineer. 

When I step away from deploying servers or training models, I am usually experimenting with cyberpunk and pixel art aesthetics, reverse-engineering choice-based narrative games to find the optimal storylines, or hanging out with cats.

### / Current Status

* **Building:** An AI-powered Home Automation Security Hub integrating Arduino hardware with predictive behavioral analytics.
* **Learning:** Scaling full-stack web development with React and Node.js, while exploring penetration testing tools and ethical hacking repositories.
* **Deploying:** Expanding my knowledge of cloud environments, specifically routing communication between Ubuntu servers using ElasticSearch and Kibana.
* **Broadcasting:** Documenting my deep dive into Artificial Intelligence, sharing code solutions, and tracking my learning journey on my YouTube channel.
